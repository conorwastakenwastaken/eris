CoolEris [![NPM version](https://img.shields.io/npm/v/eris.svg?style=for-the-badge&color=red)](https://npmjs.com/package/eris)
====

A Node.js wrapper for interfacing with Discord. This is an updated version of Eris. All initial credits to abalabahaha.

Installing
----------

You will need NodeJS 14.0.0+. If you need voice support you will also need Python 2.7 and a C++ compiler. Refer to [the Getting Started section of the docs](https://abal.moe/Eris/docs) for more details.

```
npm install --no-optional eris
```

If you need voice support, remove the `--no-optional`.
