# Contributing

Thanks for considering contributing!

A few rules of thumb:

- Code contributions should match the existing code style. Run `npm run lint` to check, and `npm run format` to fix some problems. Note that while the minimum Node version to run Eris is 14.0.0+, you will need to upgrade Node to 18.18+, if you'd like to contribute to Eris.
- Check the dev branch and any open PRs to make sure someone hasn't worked on the same thing already.
- Pull requests should point to the dev branch.
